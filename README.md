# KALBASO Termux Studio 🇪🇬
### أول استوديو عربي لتشغيل Termux و Git بلمسة واحدة

KALBASO Termux Studio هو تطبيق أندرويد يفتح Termux كامل جوا التطبيق، تنزل مكتبات Python وقوالب جاهزة ومشاريع GitHub مباشرة - بواجهة عربية 100%.

### ✨ المميزات
- واجهة عربية كاملة
- ربط حقيقي مع GitHub
- تثبيت تلقائي للمكتبات
- فتح Termux من داخل التطبيق
